The o!TR Docs now live in [`apps/docs`](https://github.com/osu-tournament-rating/otr-web/tree/master/apps/docs) of the [otr-web](https://github.com/osu-tournament-rating/otr-web) repository, which deploys them to [docs.otr.stagec.net](https://docs.otr.stagec.net/). The history of this repository up to the move is part of otr-web's history. Please open issues and pull requests in otr-web.

This repository is retired and no longer deploys. Its `quartz/v4` branch is still in use: it is the [Quartz](https://quartz.jzhao.xyz/) fork that otr-web's `apps/docs/quartz` submodule points at.
